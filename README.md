# 🎓 THE PROJECT ARCHIVE — 50 STUDENT SHOWCASE

> **50 Students. 25 Team Projects. One Central Showcase.**  
> A premium editorial-style digital exhibition portal designed for college faculty and visitors to seamlessly discover, search, preview, and access student full-stack web projects.

---

## 🌟 Overview & Objectives

**The Project Archive** is a centralized web application created to showcase the web development projects of 50 college students (S5 BCA Full Stack Development course). 

Students worked in **paired 2-member teams** (Roll 01 & 50, Roll 02 & 49, etc.), producing **25 combined web applications**. This showcase provides an interactive editorial directory where evaluators and visitors can instantly search student names, inspect project categories, access live deployed websites, and view source code repositories on GitHub.

---

## 🛠️ Tech Stack & Architecture

### **Frontend & Design System**
- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Animations**: [Framer Motion v12](https://www.framer.com/motion/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Font **Kanit** & **Monospace**

### **Architecture & Data Processing**
- **Client-Side Data Architecture**: Immutable typed student repository array (`src/data/projectsData.ts`).
- **Procedural SVG Graphics Engine**: Dynamic vector artwork generation (`getProceduralPreviewSvg`) ensuring crisp theme previews without external asset dependencies.
- **Search & Filtering Engine**: Sub-millisecond live search matching across student names, roll numbers, project titles, tech tags, and categories.

---

## ✨ Key Features

1. **Editorial Numbered Directory (`01` – `25`)**:
   - Minimalist, high-contrast aesthetic inspired by modern SaaS landing pages.
   - Massive typography with hover translations and dynamic color highlights.

2. **Smart Submission & Live Host Detection**:
   - **Active Deployed Sites**: Direct access via `[ Live Website ↗ ]` buttons.
   - **Code-Only Repositories**: Clear `[ No Live Web Host ]` indicator pill with direct `[ GitHub Repo ↗ ]` access.
   - **Unsubmitted Projects**: Visual `NOT SUBMITTED YET` badges for real-time submission tracking.

3. **Interactive Detail Modal Overlay**:
   - Clicking any team row opens a glassmorphism modal with full team partner rosters, detailed project descriptions, tech stack tags, preview graphics, and action links.

4. **Live Search Bar & Dynamic Counters**:
   - Instant filtering with dynamic statistics counters tracking submitted teams vs live hosted websites.

## 🚀 Local Setup & Installation

Follow these steps to run the showcase project locally on your machine:

### **1. Prerequisites**
Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### **2. Clone the Repository**
```bash
git clone https://github.com/Athhull/project-showcase-website.git
cd project-showcase-website
```

### **3. Install Dependencies**
```bash
npm install
```

### **4. Start Development Server**
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### **5. Build for Production**
```bash
npm run build
```
